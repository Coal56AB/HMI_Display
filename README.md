# Экранчик STM32 / ESP32-S3

Новая платформа: [ESP32-S3, сборка и подключение](Firmware/ESP32/README.md).
В музыкальной ветке к ней подключён [экран + USB-MIDI](DisplaySrc/esp32/README.md).
`BUILD_ESP32.cmd` собирает ESP-прошивку без загрузки на плату.

Общая платформа: STM32F103C8, ILI9486 320×480, XPT2046 и SPI Flash W25Q16.
Конкретный интерфейс, его протокол и симулятор находятся в сменной папке `DisplaySrc`.

## Структура

- `Firmware/` — драйверы, конфигурация платы, загрузчик ресурсов, диагностика и общий цикл приложения.
- `DisplaySrc/` — самостоятельный модуль GUI: C-код, ресурсы, команды, журнал, симулятор, генерация, тесты и его документация.
- `Scripts/Build/` — выбор модуля и сборка общей прошивки.
- `Scripts/Flash/` — общий загрузчик ресурсов через UART.
- `Docs/` — подключение, сборка и контракт подключения GUI.
- `Release/` — готовая прошивка и ресурсы для загрузки без сборки, хранятся в Git.

## Запуск

- `SIMULATOR.cmd` — симулятор выбранного по умолчанию `DisplaySrc`.
- `BUILD.cmd` — ресурсы модуля и прошивка STM32; результат в `Release/<имя модуля>/`.
- `START.cmd` — загрузчик ресурсов. Запуск программы сам по себе ничего не прошивает.
- `DisplaySrc/Scripts/build_simulator.cmd` — сборка EXE внутри самостоятельного модуля.

Для другого интерфейса: `BUILD.cmd --display-dir D:\MyDisplaySrc`.
Описание исходников и ресурсов берётся из `module.json`, а не из жёстко заданного списка ПЧ.

[Подключение и инструменты](Docs/SETUP.md) · [Контракт модуля](Docs/DISPLAY_MODULE.md) · [Текущий GUI](DisplaySrc/README.md)

Промежуточные файлы создаются только при сборке и не хранятся в Git.
`Scripts/Build/clean.ps1` удаляет промежуточные каталоги, сохраняя готовые `Release`.

Платформа использует фиксированный API v2. Подключение интерфейса не требует
изменений C-кода. Пустой модуль расположен в `Firmware/Api`; без манифеста
в `DisplaySrc` BUILD собирает его. Проект для сборки создаётся в `.build/Keil`.
