# Формат production-сцен

`export_html_scene.mjs` не сохраняет пиксели. Каждая команда `CStripPreview` превращается в один примитив C-рендерера: заливку, градиент, линию, линию заданной толщины, рамку, скруглённый прямоугольник, окружность, треугольник или текст.

Генератор выполняет два уровня дедупликации:

1. Глобальный словарь уникальных примитивов. Геометрически и стилистически одинаковая команда существует во Flash один раз.
2. Общие DOM-блоки. Последовательности команд шапки, навигации, карточек, схемы, диалогов и других элементов существуют один раз; сцена хранит только список номеров блоков.

Статистика текущего экспорта:

- 47 сцен;
- 91 948 исходных вхождений команд;
- 10 402 уникальных примитива;
- 810 общих блоков;
- 277 033 байта данных сцен вместо прежних 1 398 067 байт.

Файлы `Assets/html_rgb565` и `Assets/c_frames` — исключительно тестовые артефакты и не компилируются в библиотеку.
