# Воспроизведение эталонов

Эталонные `.commands.json` и `.rgb565` получены непосредственно после `CStripPreview.build()/replay()` при фиксированном времени `02.09.2026 14:32`, отключённой анимации и детерминированных выборках графиков.

Для каждой сцены инструментирование сериализует `CStripPreview.commands` в JSON и копирует исходные 16-битные полосы WASM до преобразования в Canvas RGBA. Поэтому файлы `html_rgb565` не являются браузерным скриншотом с повторной квантизацией цвета.

После экспорта выполните `make references && make test`. `Scripts/compare_frames.py` создаёт PNG и diff и завершает работу с ошибкой при любом отличающемся пикселе.
