# Готовые изображения во Flash

ExternalFlash теперь использует готовые RGB565-фоны всех 47 сцен, включая схему,
панели, статические надписи и варианты состояния. STM32 читает цветовые серии и
копирует пиксели в буфер, а не исполняет команды геометрии для фона.

Изменяемые значения не запечены: перед генерацией исключаются заменяемые
демонстрационные надписи. На плате живой текст накладывается прозрачно, фон
переключателей и индикация блоков меняются отдельно. Телеметрия и графики работают
поверх растра. При переключении состояния выбирается готовый вариант сцены;
повторяющиеся участки разных вариантов хранятся один раз.

## Что хранится

- 320×8 RGB565 на одну полосу; 60 полос на сцену.
- 1050 уникальных полос вместо 2820; сжатие PackBits без потерь.
- Полный `hmi_assets.bin`: **1 187 552 байта**, CRC32 **913191ab**.
- Остаток W25Q16: 934089 байт. Шрифты и прежние таблицы включены в этот же образ.
- В RAM остаётся только буфер 5 КиБ, кеш ресурсов и данные приложения.

Таблица полос размещена после исходных ресурсов, смещения записаны little-endian
uint32. Токен потока: младшие 7 бит — число пикселей минус один; старший бит
означает повтор одного RGB565-цвета, иначе идут literal RGB565-пиксели.
Декодер выводит лишь пересечение с текущей dirty-областью. Геометрический кеш
2304 байта удалён из ExternalFlash, освободив RAM для телеметрии.

Для изменения состояния блоков используется замена ключевых фоновых цветов
4324/6531/12610/16547 в пределах штатного блока. При разряде фон DC и, для активного
разряда, инвертора становится жёлтым; символы и рамки сохраняются.

## Обновление платы

1. Прошить `Firmware/BluePillHMI/MDK-ARM/ExternalFlash/ExternalFlash.hex` в STM32.
2. Закрыть программы, занимающие USB–UART. Открыть `START.cmd` в корне,
   выбрать **«Загрузить ассеты»** и указать фактический COM-порт. Скрипт сам отправляет PCHR для
   `NVIC_SystemReset()`, затем записывает образ и проверяет его CRC.
   В окне при стирании и записи показывается полоса прогресса; при записи — также скорость
   и оставшееся время. Для образа 1,16 МБ на 115200 бод только передача занимает
   не менее 101 секунды, дополнительно нужны стирание и проверка CRC.
3. Дождаться подтверждения проверки и запустить приложение.

Старый образ ресурсов с новым HEX несовместим по длине/CRC. Если после прошивки
STM32 остановился на проверке старых ресурсов, программный UART-сброс остаётся
доступен; отладчик должен быть в Run. Повторно нажимать физический Reset не нужно.

## Повторная генерация

`python DisplaySrc/Scripts/generate_rasters.py`
перегенерирует фоны из C-эталона с теми же областями заменяемого текста, обновляет
образ, длину и CRC. `generate_profiles.py` также вызывает этот этап. Изменения
статического оформления или областей замены требуют повторной генерации и записи.
