# Подключение ПЧ к платформам

`Platform/Common` содержит реализацию API v2, обработку команд и журнал.
STM32 и ESP32 собирают одни исходники из `module.json`. Общий код не включает
HAL или ESP-IDF. `esp32/manifest.py` преобразует этот список для CMake 3.16.

STM32 предоставляет ресурсы и журнал через внешнюю W25Q16. ESP32 читает
тот же `Assets/hmi_assets.bin`, встроенный в приложение, и хранит журнал
в разделе `pch_journal`. Ресурсы проверяются общим кодом CRC до запуска GUI.
`esp32/partitions.csv` рассчитан на 4 МиБ: приложение начинается с 0x10000,
занимает до 0x300000 байт, журнал — 0xd8000 байт с адреса 0x310000.
Адаптер переводит логические адреса журнала относительно `JOURNAL_BASE`
в смещения раздела; запись и стирание ограничены этим разделом.

`esp32/services.cpp` подключает сервисы до проверки ресурсов, затем запускает
USB Serial/JTAG для связи с симулятором. При `PCH_USE_USB=0` используется
UART1 на GPIO1/2. UART0 остаётся консолью платформы. За один проход передаются до 128 байт
в парсер ПЧ с очередью на 255 байт; ошибки UART сбрасывают входной поток и
доставляются через `DISPLAY_RX_ERROR`. Все события приложения выполняются
в задаче интерфейса.

Симулятор открывает COM-порт с заранее отключёнными DTR и RTS, чтобы не
запускать аппаратную последовательность сброса ESP при подключении.

Рендерер ПЧ сохраняет логическую геометрию 320×480 и существующую отрисовку
изменённых областей. При `HMI_ROTATED_DISPLAY=1` вывод использует поворот из
`Firmware/Api/display_renderer.h` и отдельный буфер размером с полосу рендерера.
Координаты касаний преобразуются обратно из 480×320. Отмена касания сбрасывает
жест без нажатия. STM32 не выделяет дополнительный буфер поворота.

Расширение ESP32 также задаёт `HMI_BOOT_WIDTH=320 HMI_BOOT_HEIGHT=480`:
загрузочный экран имеет ту же ориентацию, что и интерфейс ПЧ, начиная
с первого этапа инициализации LCD.

## Проверки

Из корня репозитория, с GCC и mingw32-make в PATH:

```text
mingw32-make -C DisplaySrc -j2 PYTHON=python
mingw32-make -C DisplaySrc test PYTHON=python
python DisplaySrc/Tests/check_module.py
python Scripts/Build/build_firmware.py
powershell -File Firmware/ESP32/build.ps1
powershell -File Firmware/ESP32/build.ps1 -Environment template
```

`check_module.py` собирает реальный адаптер по манифесту в двух конфигурациях.
Он сравнивает изображения после обратного поворота, проверяет навигацию,
отмену касания, чтение ресурсов и запись журнала на модели Flash.
Эти проверки не заменяют запуск прошивки на плате.
