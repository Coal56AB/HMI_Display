# MusicBox HMI UART v1

115200, 8N1. PA9 TX, PA10 RX, общий GND, уровни 3,3 В. Отдельный UART панели;
не соединять с передатчиком на линии моторного контроллера.

Кадр: `A5 5A LEN SEQ CMD PAYLOAD CRC_LO CRC_HI`. LEN 0–240. CRC16-CCITT,
полином 0x1021, начальное 0xFFFF, по LEN..PAYLOAD. Числа LE.

## Контроллер → панель

| CMD | Payload |
|---|---|
| 0x40 STATE | 50 байт каждые 100 мс |
| 0x41 TITLE | до 48 байт UTF-8 без завершающего нуля |
| 0x42 MIDI_EVENT | u32 time_ms, u8 motor, u8 note, u8 velocity |
| 0x43 MIDI_CLOCK | u32 time_ms |
| 0x51 ACK | один байт 0=принято, 1=недоступно, 2=неверное значение; SEQ команды |

STATE: `u8 version=1, u8 flags, u8 sleep, u8 reset, u8 microstep_raw, u8 mask,
u32 position_ms, u32 duration_ms`, затем шесть записей `u8 flags, u8 note,
u32 frequency_mHz`. 440 Гц = 440000 мГц.

Общие flags: bit0 связь с моторами, bit1 проигрывание, bit2 пауза, bit3 MIDI подключён.
Флаги мотора: bit0 ENABLE, bit1 STEP, bit2 DIR. Моторы 0–5, note 0–127 или 255.

MIDI_EVENT: velocity=0 закрывает ноту, >0 открывает. Новая нота закрывает прежнюю
на том же моторе. Время монотонное для сессии. MIDI_CLOCK с меньшим временем
начинает новую историю. Отправляйте точные события для коротких нот между STATE.

## Панель → контроллер

0x50 ACTION: `u8 action, u8 motor, u32 value`.

| Action | Значение |
|---|---|
| 0 STOP_ALL | немедленная остановка всех |
| 1 PLAY_PAUSE | запуск/пауза/продолжение композиции |
| 2 SEEK | мс, сохранять состояние паузы |
| 3 FREQUENCY | 20000–4000000 миллигерц |
| 4 ENABLE | 0/1 |
| 5 START_STOP | STEP 0/1 |
| 6 DIR | 0/1, корректная остановка/возобновление при смене |
| 7 MICROSTEP | raw 0/1/2/3/7 |
| 8 SLEEP | 0/1 |
| 9 RESET | остановить STEP, снять ENABLE и включить RESET |
| 10 ACTIVATE | снять RESET/SLEEP, не запускать моторы |

Вид подписи и ширина сохраняются локально, UART-команда не нужна.
Панель ожидает одну команду; максимум 3 передачи того же кадра с интервалом
300 мс. STOP_ALL заменяет ожидающую команду новым SEQ.

Контроллер распознаёт повтор `(SEQ, payload)` в течение 2 секунд и возвращает
прежний ACK, не повторяя действие. Особенно важно для PLAY_PAUSE. ACK означает
принятие, фактическое состояние приходит в STATE. Ошибки исполнительной платы
не должны подменяться оптимистичными показаниями.

Битый CRC/версия/длина игнорируются. 1500 мс без STATE гасят индикацию и
блокируют команды, кроме STOP. Физическая остановка при обрыве — ответственность
watchdog моторного контроллера.
