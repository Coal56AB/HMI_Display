# DisplaySrc — подключаемый интерфейс

В templates здесь оставлена только инструкция. Исходники пустой реализации
находятся в Firmware/Api/display_empty.c; BUILD.cmd собирает её автоматически.

Добавьте сюда конкретный интерфейс: код отрисовки и касаний, ресурсы, генератор,
симулятор, его сборку, тесты и документацию. Генерация ресурсов и симулятор должны
работать независимо от родительского проекта.

Общая платформа вызывает display_init, display_event и display_step.
Контракт принадлежит платформе: Firmware/Api/display_api.h, версия 2.
Модуль использует переданный DisplayPlatform и не включает board.h или HAL.
Также он предоставляет константу display_module с версией API и описанием ресурсов.

Для подключения достаточно заменить в сборке display_empty.c исходниками модуля
и добавить include-пути/defines. C-код платформы менять не нужно.
BUILD.cmd читает module.json и создаёт проект в .build/Keil, сохраняя исходный проект.
Модуль может иметь автономный CONNECT.cmd с окном выбора проекта Keil.

Пример готовой реализации расположен в ветке PCH_HMI.
Подробный контракт: [Docs/DISPLAY_MODULE.md](../Docs/DISPLAY_MODULE.md).
