# ESP32-S3: платформа экрана

Самостоятельный ESP-IDF 5.4.0 / PlatformIO `espressif32@6.10.0` проект для
ESP32-S3 с 4 МБ Flash.
Используется профиль DevKitC-1 с переопределённым размером Flash. PSRAM не требуется.
ILI9486 с Raspberry Pi SPI-адаптером, RGB565, 480×320 в альбомной ориентации;
тач XPT2046. Проект для STM32 находится в `Firmware/BluePillHMI`.

## Подключение

Подключить экран к ESP32-S3. Значения GPIO и калибровка находятся в
`main/board_config.h`. Подписанные контакты GPIO на плате — не номера её ножек.

| Сигнал дисплея | ESP32-S3 GPIO |
|---|---:|
| SCK, T_CLK | 12 |
| MOSI, SDI, T_DIN | 11 |
| T_DO / MISO | 13 |
| LCD_CS | 10 |
| LCD_DC / RS | 9 |
| LCD_RST | 6 |
| T_CS | 8 |
| T_IRQ / PENIRQ | 7 |
| GND | Общая земля |

У имеющегося модуля экран питается от подписанного +5V, сигналы ESP32 — 3,3 В.
Внешняя Flash для дисплея и сенсора не требуется.

GPIO19/20 зарезервированы под native USB. У компактной платы на фото цифры
1–13 обозначают GPIO; все подключения дисплея используют контакты 6–13.
UART0 GPIO43/44 (TX/RX) доступен для внешнего USB-UART.
На плате с одним USB-C для прошивки через USB удержать BOOT, нажать RESET,
отпустить RESET и BOOT, затем выбрать USB-порт загрузчика. На DevKitC можно
использовать отдельный USB-UART-разъём без этой ручной последовательности.
Контакт подсветки, если он отдельный, подключается
по схеме конкретного дисплейного модуля.

## Сборка и проверка

Из корня подмодуля:

```powershell
./Firmware/ESP32/build.ps1 -Environment template
./Firmware/ESP32/build.ps1 -Environment display
```

`BUILD_ESP32.cmd` запускает сборку `display`. Требуется установленный PlatformIO.
По умолчанию используется Python из `%USERPROFILE%/.platformio/penv/Scripts`;
другой интерпретатор с PlatformIO можно задать аргументом `-Python`.
Результаты сборки находятся в `.build/esp32`.

- `template`: цветные полосы и крестик в месте касания, без прикладного модуля.
- `display`: подключает `DisplaySrc/esp32/CMakeLists.txt`, если он есть в ветке;
  иначе запускает тот же тест полос. Платформа не зависит от родительского репозитория.

Для явно выбранной прошивки платы:

```powershell
./Firmware/ESP32/build.ps1 -Environment template -Upload -Port COM7
# После проверки полос и тача:
./Firmware/ESP32/build.ps1 -Environment display -Upload -Port COM7
```

Выбрать свой COM-порт USB-загрузчика либо USB-UART. Обычная сборка ничего не прошивает.
Результаты: `.build/esp32/<environment>/firmware.bin`, `bootloader.bin`, `partitions.bin`.
При ручной записи нужны все три: bootloader `0x0`, partitions `0x8000`, firmware `0x10000`.
Частота SPI дисплея — 20 МГц. GPIO и калибровка сенсора задаются
в `main/board_config.h`. Для ILI9486 без Pi-адаптера выберите
`HMI_LCD_RPI_ADAPTER=0`. После подключения проверьте касания в углах экрана.

При запуске показываются этапы подготовки экрана и сенсора, затем цветные полосы.
Нажатие на экран отмечается крестиком.

## Граница базового проекта

Базовый проект обслуживает дисплей и сенсор. Конкретный интерфейс подключается
из `DisplaySrc/esp32`; его наличие для сборки и запуска шаблона не требуется.
