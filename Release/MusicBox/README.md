# MusicBox

`display.hex` — STM32F103C8 + ILI9486/XPT2046, интерфейс 480×320.
Ресурсы встроены; отдельный образ W25Q16 не нужен. Последний сектор W25Q16
используется для пользовательских настроек.

Сборка: Keil Arm Compiler 6.19, 0 ошибок и предупреждений.
Описание и UART: `DisplaySrc/README.md`, `DisplaySrc/PROTOCOL.md`.
Хостовые тесты пройдены; физическая плата этой версией не прошивалась.
Калибровка XPT2046 сохранена из templates.
