# Пустой шаблон API v2

`display.hex` — STM32F103C8, ILI9486 320×480, без интерфейса и внешних ресурсов.
После старта показывается общая терминалка инициализации.
Загрузите HEX через ST-Link; адреса записаны в файле. Внешнюю Flash прошивать не нужно.
Подключение интерфейса описано в `Docs/DISPLAY_MODULE.md`.
