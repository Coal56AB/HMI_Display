# Готовая сборка ПЧ HMI

Версия интерфейса: **1.2.4**, платформа API v2, исправленный шрифт запуска. Плата STM32F103C8, дисплей ILI9486 320×480,
внешняя Flash W25Q16. Прошивка и ресурсы поставляются согласованной парой.
Компиляция для их загрузки не требуется.

1. Через ST-Link и программу прошивки STM32 откройте `display.hex` и запишите
   во внутреннюю Flash STM32. Адреса уже содержатся в HEX.
2. Подключите UART дисплея (115200, 8N1), запустите корневой `START.cmd`.
   Для загрузчика нужны Python 3.7 и зависимости `Scripts/Flash/requirements.txt`.
3. В загрузчике выберите COM-порт и выполните запись ресурсов во внешнюю Flash.
   Он автоматически читает `DisplaySrc/Assets/hmi_assets.bin` — в этом коммите
   это точная копия `resources.bin`. Дождитесь успешного завершения.
4. Перезапустите экранчик и проверьте сообщения инициализации.

Подключение: [Docs/SETUP.md](../../Docs/SETUP.md).
Эти файлы соответствуют исходникам коммита, в котором они опубликованы.
При изменении интерфейса обновляйте оба файла вместе с исходниками.
